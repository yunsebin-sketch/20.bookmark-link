폴더 추가 기능을 만들어줘.

- 새 폴더 버튼은 헤더 컴포넌트의 새 링크 버튼 좌축에 배치
- 클릭 시 화면 가운데에 모달이 열리도록 구현
- 모달 안에는 폴더 이름 입력 인풋, 취소 버튼, 저장 버튼 배치
- 저장 시 새 폴더 좌측 사이드바에 즉시 추가될 것

# 주의사항

- 컴포넌트 단위로 적절히 분할해서 구현
- 결과는 컴포넌트 단위로 보고해

# 기타

- 결과는 한국말로 다음과 같이 설명해줘
- 컴포넌트 단위로 설명해(이름, 경로, 역할)
- 일반 컴포넌트 -> 페이지 컴포넌트 순으로 설명해줘
- 페이지 컴포넌트 설명에는 포함된 일반 컴포넌트 목록도 보여줘
