링크 추가 기능을 구현해줘.

- 먼저 특정 링크의 오픈 그래프 정보를 추출하는 API부터 구현
- 새 링크 페이지에서 저장 버튼을 누르면 링크를 저장해
- 저장 시 오픈 그래프 API로 제목, 설명, 썸네일, 링크 주소를 함께 수집해서 저장해줘
- 새롭게 보관되는 링크 카드에 썸네일도 함께 표시해줘

# 주의사항

- 컴포넌트 단위로 적절히 분할해서 구현
- 결과는 컴포넌트 단위로 보고해

# 기타

- 결과는 한국말로 다음과 같이 설명해줘
- 컴포넌트 단위로 설명해(이름, 경로, 역할)
- 일반 컴포넌트 -> 페이지 컴포넌트 순으로 설명해줘
- 페이지 컴포넌트 설명에는 포함된 일반 컴포넌트 목록도 보여줘
